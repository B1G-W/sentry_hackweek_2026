# Seer Snake

A Nokia-style Snake game where the snake is [Sentry Seer](https://blog.sentry.io/seer-sentrys-ai-debugger-is-generally-available/), Sentry's AI debugger.

**Play it:** https://b1g-w.github.io/sentry_hackweek_2026/

- Eat bugs (not apples) — the HUD counts bugs fixed
- Seer's all-seeing pyramid head tracks your direction
- Arrows / WASD on desktop, swipe on mobile
- High score persists via localStorage

Built with Claude Code during Sentry Hackweek 2026.
